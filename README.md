The one line a smart fridge texts its owner at 3am, written for make.fun's The 3AM Fridge Text.

> 3am. The freezer and I have been talking. Please stop standing here in your underwear eating cold pasta like a raccoon.

The fridge is not reporting a fault or a missing item — it has been gossiping with the freezer, and it has an opinion about the owner's 3am behaviour, delivered with the total lack of shame only a machine that watches you eat in the dark can have.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (exactly the line, no trailing newline). Set `OUTPUT_DIR` to write elsewhere for a local run.
